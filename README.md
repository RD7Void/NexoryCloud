## 🎉 Bem-vindo ao Nexory Cloud!

Seu novo gerenciador de projetos com download integrado,
GitHub e Discord Rich Presence.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🔐 Login
- 🔗 Entre com sua conta do Discord
- 👤 Escolha seu nick e tag personalizados
- 🖼️ Seu avatar do Discord aparece automaticamente
- 💾 Sessão salva automaticamente

## 📦 Projetos
- 🆕 Publique seus projetos para a comunidade
- 🖼️ Adicione imagens e descrições
- 📂 Suporte a GitHub Releases, repositórios e links diretos
- 🏷️ Tipos de arquivo detectados automaticamente (APK, ZIP, EXE)
- ✏️ Edite seus projetos a qualquer momento
- 🔍 Busque projetos por nome ou autor

## ⬇️ Downloads
- 📥 Baixe projetos com um clique
- 📦 Extração automática de arquivos ZIP
- 📊 Acompanhe o progresso dos downloads
- 📲 Instale APKs direto no celular via ADB

## 🗂️ Biblioteca
- 📚 Veja todos os seus projetos instalados
- ▶️ Abra projetos rapidamente
- 🗑️ Desinstale com limpeza completa de arquivos

## 🐙 GitHub
- 🔗 Conecte sua conta do GitHub
- 📋 Navegue seus repositórios e releases
- 🆕 Crie repositórios direto pelo app
    com templates (.gitignore, licença, README)
- 🖼️ Faça upload de imagens para seus repos

## 🎮 Discord Rich Presence
- 🟢 Mostre que está usando o Nexory Cloud no Discord
- 📌 Atividade muda conforme a aba que você está
- 📦 Mostra o projeto que você está vendo
